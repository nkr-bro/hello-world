# Твоя часть

`simulation/` — игровая логика, `simulation/models/` — модели данных, `backend/` — будущий сервер.

Начни с дохода сайтов и смены годов. Сейчас реализовано создание сайта за $50 при стартовом балансе $300.

Запускай `npm run dev` из корня репозитория. При изменении моделей и функций предупреди друга, чтобы он обновил интерфейс.
