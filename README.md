# Hello World (1995–2026)

Браузерная игра о развитии интернет-бизнеса: от одного компьютера в 1995 году до компании в 2026-м.

Это стартовый прототип, а не завершённая игра. Реализованы комната с компьютером, стартовые $300 и создание сайтов по $50. Переход между годами, доход и сохранения пока не реализованы.

## Запуск

Нужны Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Нажмите на экран компьютера, клавишу E или кнопку «Открыть компьютер», затем создайте сайт.

```sh
npm run typecheck
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Прогресс сбрасывается при обновлении страницы.

## Структура: кто за что отвечает

### `my-part/` — твоя часть

- `simulation/models/GameState.ts` — состояние игры: деньги, год и сайты.
- `simulation/createWebsite.ts` — создание сайта и списание денег.
- `backend/` — место для будущего сервера, пока только описание.

Здесь развивай экономику, доход сайтов, смену годов и сохранения. Логика симуляции не зависит от React и Phaser.

### `friend-part/` — часть друга

- `App.tsx` — интерфейс, баланс и окно создания сайта.
- `components/GameCanvas.tsx` — подключение сцены к React.
- `game/RoomScene.ts` — комната и компьютер на Phaser.
- `style.css` — оформление.
- `main.tsx` и `vite-env.d.ts` — запуск интерфейса и типы Vite.

Здесь друг развивает комнату, персонажа, взаимодействия и окна. Интерфейс использует готовую логику из `my-part/simulation/`.

### Общие файлы в корне

`package.json`, `package-lock.json`, `index.html`, `tsconfig.json`, `vite.config.ts`, `.gitignore` и `.wakatime-project` нужны обоим. Команды запуска выполняйте из корня проекта. Это одна игра с двумя рабочими папками, поэтому отдельно устанавливать зависимости в каждой папке не нужно.

Стек: React + TypeScript + Phaser 3 + Vite.

## Совместная разработка

Работайте каждый в своей папке и отдельной ветке, объединяйте изменения через pull request. Изменения полей `GameState` и функций симуляции согласуйте между собой: их использует интерфейс друга.

Ближайшие задачи: тебе — доход сайтов, развитие по годам до 2026 и сохранение прогресса; другу — перемещение персонажа, оформление комнаты и окон.

## Hackatime / WakaTime

`.wakatime-project` задаёт общее имя проекта `hello-world`. Каждый участник отдельно настраивает расширение своего редактора и подключение к Hackatime. Этот файл сам по себе не включает отслеживание времени. Не добавляйте API-ключи или личный `.wakatime.cfg` в репозиторий.

## Проверка зависимостей

Стартовая сборка и проверка TypeScript проходят. На момент создания `npm audit` сообщает о 5 предупреждениях высокого уровня в цепочке инструментов разработки Vite → tinyglobby → picomatch. Автоматическое исправление без смены основной версии недоступно; перед публикацией сервера разработки проверьте обновления. Сервер Vite предназначен для локальной разработки, для публикации игры используйте статическую сборку `dist/`.
