# One Man Internet (1995–2026)

Браузерная игра о развитии интернет-бизнеса: от одного компьютера в 1995 году до компании в 2026-м.

Это стартовый прототип, а не завершённая игра. Реализованы комната с компьютером, стартовые $300 и создание сайтов по $50. Переход между годами, доход и сохранения пока не реализованы.

## Запуск

Нужны Node.js 22.12+ и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который выведет Vite. Нажмите на экран компьютера, клавишу E или кнопку «Открыть компьютер», затем создайте сайт.

```sh
npm run typecheck
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Прогресс сбрасывается при обновлении страницы.

## Структура

- `src/components/` — React-интерфейс и контейнер Phaser.
- `src/game/` — сцены Phaser 3.
- `src/simulation/` — независимая игровая логика.
- `src/simulation/models/` — типы состояния игры и сайтов.
- `backend/` — место для будущего серверного API (пока только описание).

Стек: React + TypeScript + Phaser 3 + Vite. Зависимости зафиксированы в `package-lock.json`.

## Совместная разработка

Один участник может развивать `simulation/` (экономика, годы, модели), другой — `game/` и `components/` (комната, взаимодействия, окна). Делайте изменения в отдельных ветках и объединяйте через pull request.

Ближайшие задачи: доход сайтов, развитие по годам до 2026, сохранение прогресса и перемещение персонажа.

## Hackatime / WakaTime

`.wakatime-project` задаёт общее имя проекта `one-man-internet`. Каждый участник отдельно настраивает расширение своего редактора и подключение к Hackatime. Этот файл сам по себе не включает отслеживание времени. Не добавляйте API-ключи или личный `.wakatime.cfg` в репозиторий.

## Проверка зависимостей

Стартовая сборка и проверка TypeScript проходят. На момент создания `npm audit` сообщает о 5 предупреждениях высокого уровня в цепочке инструментов разработки Vite → tinyglobby → picomatch. Автоматическое исправление без смены основной версии недоступно; перед публикацией сервера разработки проверьте обновления. Сервер Vite предназначен для локальной разработки, для публикации игры используйте статическую сборку `dist/`.
